☁️ 云存储设置

配置后数据将存到云端，换手机/换浏览器数据不丢失。不配就默认存在浏览器本地。

🟢 Supabase 免费配置步骤

1. 打开 supabase.com 注册 (GitHub登录即可)
2. 创建项目 → 记住数据库密码
3. 进入项目 → Settings → API
4. 复制 Project URL 和 anon public key 填到下方
5. 进入 SQL Editor，粘贴执行下方 SQL 建表：

-- 创建省钱记录表 CREATE TABLE savings ( id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY, amount NUMERIC(10,2) NOT NULL, note TEXT DEFAULT '', source_id TEXT DEFAULT '', created_at TIMESTAMPTZ DEFAULT NOW() ); -- 创建领券记录表 CREATE TABLE claimed ( id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY, source_id TEXT NOT NULL, claimed_at TIMESTAMPTZ DEFAULT NOW(), note TEXT DEFAULT '' ); -- 开启公开访问 (anon key) ALTER TABLE savings ENABLE ROW LEVEL SECURITY; ALTER TABLE claimed ENABLE ROW LEVEL SECURITY; CREATE POLICY "允许公开读写 savings" ON savings FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "允许公开读写 claimed" ON claimed FOR ALL USING (true) WITH CHECK (true);

📤 数据管理

🤔 为什么不能用飞书/Notion？

Notion API 和飞书 API 不允许从浏览器直接调用（CORS限制），必须有个服务器中转。

Supabase 是最佳免费方案：专为前端设计，CDN引入JS库即可直连数据库，无需任何服务器。

也可以配合 Cloudflare Workers(免费10万次/天) 做中转代理，就能用飞书/Notion了。
