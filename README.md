# 🧧 外卖省钱半自动领券助手


| ✅ 本工具：聚合信息 + 你手动领 | **零** | 你只是看了个网页/链接，然后自己打开App领 |

> **核心原则：人手动操作官方App，工具只负责帮你整理信息和记住流程。**

---

## 快速开始

```bash
cd waimai-coupon-agent

# 查看所有券源（按平台）
python3 waimai-agent.py list
python3 waimai-agent.py list 美团
python3 waimai-agent.py list 银行

# 查看今日领券流程
python3 waimai-agent.py routine

# 搜索特定类型券
python3 waimai-agent.py search 每日
python3 waimai-agent.py search 拼

# 打开某个券源链接（浏览器）
python3 waimai-agent.py open meituan_member

# 记录省了多少钱
python3 waimai-agent.py track add 8.5 用了美团5元券

# 查看省钱统计
python3 waimai-agent.py track stats

# 检查券源链接是否有效
python3 waimai-agent.py monitor
```

## 📅 每日领券 SOP

```
☀️ 上午（5分钟）
  → 美团外卖App：天天领券 + 摇一摇
  → 饿了么App：领红包 + 膨胀
  → 支付宝：搜「外卖」领红包

🌤️ 中午（点餐时）
  → 看看拼好饭/拼团有没有更便宜的
  → 建行生活App领外卖券（如果有建行卡）

🌙 下午（摸鱼时）
  → 云闪付App检查外卖券
  → 什么值得买逛逛线报

📆 特殊日子
  → 每周三：招行掌上生活5折
  → 每月初：续费会员、各银行App领月券
```
